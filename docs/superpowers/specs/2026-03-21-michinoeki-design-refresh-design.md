# 道の駅サイト デザイン調整仕様

## 1. 目的

この仕様は、現在の MVP を「情報を探せるサイト」から「週末にふらっと出かけたくなる観光サイト寄りの入口」へ引き上げるためのデザイン調整方針を定義する。

今回の調整では、検索しやすさを維持したまま、旅の気分、空気感、ワクワク感を UI に加えることを目的とする。

重視する価値は次のとおり。

- ひと目で「道の駅を探すサイト」だと分かる
- 週末のドライブ先を探したくなる雰囲気がある
- おすすめやイベントから、検索以外の入口も作る
- 情報の信頼感や見やすさは失わない

## 2. デザインコンセプト

### 2.1 コンセプト

デザインコンセプトは「週末ドライブの入口」である。

全国の道の駅を横断検索できる実用性を土台にしながら、空、道、旅先の抜け感を感じるビジュアルを重ね、検索の前後に「気になる」「行ってみたい」を生む。

### 2.2 印象の方向

- 観光サイト寄り
- 検索性とビジュアルの両立
- 空と道を感じる爽やかな配色
- 写真とグラフィックを重ねた少し印象的な見せ方
- 「週末にふらっと出かけたくなる」軽やかな空気感

## 3. 今回のスコープ

今回のデザイン調整で対象にするのは、利用者が最初に触れる主要画面である。

- トップページ
- 検索結果一覧
- 道の駅詳細ページ
- 共通ヘッダー

今回の調整では、MVP の機能自体は増やさない。既存の検索、一覧、詳細導線を前提に、視覚設計と情報の見せ方を改善する。

## 4. トップページ

### 4.1 役割

トップページの役割は次の 3 つ。

- 探す: 検索ボックスからすぐに道の駅を探せる
- 気になる: おすすめやイベントから興味を持てる
- 出かけたくなる: 旅の気分が立ち上がる

### 4.2 構成

トップページは以下の順序で構成する。

1. ファーストビュー
2. 今週のおすすめ道の駅
3. 注目イベント
4. 都道府県から探す入口

### 4.3 ファーストビュー

ファーストビューは、検索導線を主役にしながら、旅の空気を感じる大きなビジュアル領域として設計する。

- 背景は空や道路の抜け感を感じるビジュアル
- その上にグラフィックを重ね、写真だけに依存しない印象を作る
- 中央に大きめの検索フォームを置く
- コピーは「全国の道の駅を、ひとつの入口から探せる」ことを短く伝える

### 4.4 おすすめセクション

「今週のおすすめ道の駅」は、検索しなくても眺めて楽しい入口にする。

- 数件のカードを横断的に並べる
- 駅ごとのおすすめ感が伝わる見出しにする
- 将来、人気順、季節特集、編集部おすすめなどへ広げられる構造にする

### 4.5 イベントセクション

「注目イベント」は、今動いている情報が集まるサイトだと感じさせる役割を持たせる。

- MVP ではダミーまたは将来枠として見せ方を整える
- 将来的に臨時情報、フェア、マルシェ、季節イベントなどを入れられる構造にする
- トップ全体に「今この瞬間の話題がある」印象を加える

## 5. 検索結果一覧

### 5.1 方向性

検索結果一覧は、実用性を保ちつつ、少し華やかにする。

観光サイトらしさを出しすぎて比較しにくくなるのは避け、「見やすいが少し気分が上がる」バランスを取る。

### 5.2 カード設計

一覧カードは以下の要素で構成する。

- 上部に旅っぽいグラフィックまたはプレースホルダービジュアル
- 都道府県
- 駅名
- 住所
- 営業時間
- 信頼度または基本情報確認済みの補助表示

### 5.3 表現方針

- 写真データが十分でない段階でも寂しく見えない
- 将来の画像差し替えに自然に対応できる
- ホバー時に少し浮くなど軽い動きを入れる
- 情報の優先順位がすぐ分かる余白設計にする

## 6. 道の駅詳細ページ

### 6.1 役割

詳細ページは、トップより落ち着いた印象にして、安心して情報を確認できるページとする。

役割は次の 2 つ。

- どんな場所かを感じさせる
- 行く前に必要な基本情報を確実に確認できる

### 6.2 構成

1. 駅名、都道府県、住所、概要
2. 営業時間、定休日、信頼度、参照ソース数
3. 駐車場情報
4. 設備情報
5. 将来の写真、イベント、口コミ、おすすめ枠のための余白

### 6.3 表現方針

- 旅先の案内ページのような信頼感を持たせる
- 情報ブロックを見やすい面で整理する
- トップより装飾は抑えめにする
- 将来要素を差し込みやすい骨格にする

## 7. ビジュアル方針

### 7.1 配色

配色は「空・道路・旅」を連想させる方向で設計する。

- ベースは空気感のある明るい色
- 主役色は空や道路標識を思わせる青系
- 補助色は白、淡い砂色、少しあたたかいアクセント

紫主体や暗すぎるトーンには寄せない。

### 7.2 背景と装飾

- 単色ベタ塗りではなく、グラデーションや形状で空気感を作る
- 写真とグラフィックを重ねて情報サービス感を薄める
- 各セクションに軽く表情を持たせる

### 7.3 タイポグラフィ

- 既定の無個性な印象から少し離す
- ただし可読性は最優先とする
- 見出しは旅や特集感が出るように、本文は読みやすく整理する

## 8. 文言方針

- UI の主要文言は日本語を基本とする
- 将来の英語対応は必要になった段階で言語設定を追加する
- 現時点では日本国内利用者が直感的に理解できる表現を優先する

## 9. 実装時の注意

- MVP の既存機能を壊さない
- 日本語 UI を前提に E2E と単体テストを更新する
- データがまだ十分でない部分は、将来置き換えやすいプレースホルダー設計にする
- 見た目だけでなく、検索導線の視認性を維持する

## 10. 完了条件

デザイン調整が完了したと判断できる条件は次のとおり。

- トップページが検索の入口として機能しつつ、旅に出たくなる印象を持つ
- おすすめ道の駅とイベントの見せ場が追加されている
- 検索結果カードが実用性と観光感の中間に整っている
- 詳細ページが情報確認用として見やすく、将来拡張の余白を持つ
- UI 文言が日本語で統一されている
